# Баскетбол — редактор учебных игр

Готовый статический редактор по ТЗ `TZ_Basketbol_redaktor.docx`. Автор: Гальмиз Мария Александровна.

**Для запуска нужен только `index.html`.** В нём уже находятся стили, код игры и редактора; библиотеки, установка пакетов, сервер и внешние картинки не нужны. Дважды нажмите файл, чтобы открыть редактор в браузере. Для постоянного автосохранения предпочтительнее GitHub Pages: поведение IndexedDB при открытии `file://` зависит от браузера.

## Добавление в GitHub

1. Откройте https://github.com/galmizmaria-beep/basketbol.
2. В пустом репозитории нажмите **uploading an existing file**; в заполненном — **Add file → Upload files**.
3. Загрузите `index.html` и `.nojekyll` **в корень репозитория** и сохраните через **Commit changes**. README и папки исходников можно добавить вместе с ними.
4. Откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку с загруженными файлами (обычно `main`), папку **/ (root)**, затем **Save**.
5. После успешной публикации адрес редактора: `https://galmizmaria-beep.github.io/basketbol/`. GitHub покажет актуальную ссылку в разделе Pages.

Файлы редактора загружены в репозиторий. Для публикации сайта включите GitHub Pages по инструкции выше.

Источник настроек публикации: [документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Как собрать игру

1. В «Проекте» задайте имя, язык, звук и качество медиа.
2. Оформите «Титульный лист», «Игровую площадку», героя, кольцо и мяч. Без загрузки используются встроенные SVG-иллюстрации.
3. Выберите объект на площадке: зелёная рамка позволяет двигать его и менять размер четырьмя маркерами. Shift сохраняет пропорции. В инспекторе задаются координаты, поворот, прозрачность, слой, блокировка и видимость. Обязательные объекты игры защищены от удаления; декорации можно добавлять и удалять.
4. В «Заданиях» добавьте вопросы. Поддерживаются один вариант, несколько вариантов, ввод текста, устный ответ и сортировка. Для сортировки список в редакторе задаёт правильный порядок; ученику он показывается перемешанным. Для устного ответа доступны самопроверка и «Ответ дан».
5. Настройте стиль окна задания, жизни, таймер, баллы, бонусы за серии, финальные экраны и доступность.
6. Нажмите «Тестировать». Правильный ответ запускает попадание, неправильный — промах и потерю жизни. После результата нажмите «Продолжить». Победа наступает после всех заданий при оставшихся жизнях.
7. Нажмите «Сохранить проект» для скачивания JSON со всеми медиа. «Загрузить проект» восстанавливает настройки. JSON сохраняет возможность дальнейшего редактирования; HTML-игра предназначена для учеников.
8. Нажмите «Скачать HTML», чтобы получить **автономную игру** без редактора и авторского подвала. Она работает без сети.

Изменения текста и цвета сразу обновляют предпросмотр. Числовые поля применяются после подтверждения или потери фокуса. Undo/Redo хранит до 80 изменений. Стрелки двигают выбранный незаблокированный объект на 1 px; Shift + стрелки — на 10 px. Ctrl/⌘ Z отменяет действие, Ctrl/⌘ Shift Z повторяет.

## Медиа и звук

- Изображения: PNG, JPG, WebP, GIF. Растровые изображения уменьшаются до 1000/1600/2400 px в зависимости от качества и преобразуются в WebP, если результат меньше оригинала. Прозрачность сохраняется.
- GIF сохраняется исходным, с анимацией: обычный Canvas не используется для его сжатия. Для GIF больше 3 МБ появляется предупреждение. GIF-aware оптимизатор в поставку не входит.
- Звук: MP3, WAV, OGG; отдельные файлы для событий и фоновой музыки. Без загрузки эффекты синтезируются в браузере; встроенного музыкального трека нет.
- Лимит одного файла — 25 МБ; загружаемого JSON — 100 МБ. Медиа хранятся внутри проекта, без временных внешних ссылок. При экспорте неиспользуемые медиа исключаются.
- Автосохранение использует IndexedDB. Если хранилище недоступно или заполнено, редактор сообщает об этом; скачайте JSON вручную. При наличии сохранения предлагается продолжить работу или начать заново.
- Музыка запускается после действия пользователя. Ошибка воспроизведения или изображения не останавливает проверку заданий.

## Таймер и доступность

Таймер можно отключить, установить на отдельное задание или всю игру (30–3600 секунд). По окончании времени: потеря жизни, завершение игры или дополнительные 30 секунд. В общем режиме при потере жизни таймер начинает новый интервал выбранной длительности. Во время результата и паузы отсчёт остановлен. Кнопка «+30 секунд» позволяет продлить время.

Поддерживаются клавиатура, touch, видимый фокус, высокий контраст, масштаб текста, настройка уменьшенной анимации и системный `prefers-reduced-motion`. В заданиях сортировки есть кнопки ↑/↓ помимо drag & drop. Интерфейс игры переводится на 15 языков, включая арабский с RTL; авторские тексты автоматически не переводятся.

## Genially

«Копировать для Genially» создаёт **iframe с `srcdoc`**, внутри которого содержится автономная игра. Если браузер не разрешил доступ к буферу обмена, редактор показывает код для ручного копирования.

Поддержка `srcdoc`, скриптов и максимального размера вставки зависит от настроек Genially. **Не гарантируется, что Genially примет большой iframe-код.** Надёжный альтернативный путь:

1. Скачайте игру и переименуйте её, например, в `lesson-1.html`.
2. Загрузите её рядом с редактором в GitHub.
3. В Genially вставьте URL `https://galmizmaria-beep.github.io/basketbol/lesson-1.html` как внешний веб-контент/iframe.

«Облегчить код» удаляет неиспользуемые медиа из текущего проекта и уплотняет CSS/JS экспорта. Это действие можно отменить. Любой экспорт уже исключает историю редактора, его интерфейс и неиспользуемые языки. Аудио и GIF не перекодируются. Размер проекта и HTML виден в разделе «Экспорт».

## Исходники и проверка

- `src/core.js` — модель, проверка ответов, загрузка и валидация проекта.
- `src/game.js`, `src/game.css` — автономная игра и встроенные иллюстрации.
- `src/editor.js`, `src/editor.css`, `src/shell.html` — редактор.
- `build.py` — сборка в один файл `index.html`, только стандартная библиотека Python.
- `examples/demo.basketball.json` — пример со всеми пятью типами заданий.
- `tests/` — детерминированные проверки на Node.js без сторонних пакетов.

После изменений исходников пересоберите файл:

```sh
python3 build.py
```

Запуск тестов на Node.js 18+:

```sh
node --input-type=module -e "import('./tests/run.mjs').then(async m => console.log(await m.runTests()))"
```

Пройдены 23 автоматические проверки логики: пять типов заданий, очки/бонусы, победа и поражение, повторный запуск, блокировка повторного ответа, таймер/пауза, уменьшенная анимация, все панели, drag/resize, Undo/Redo, сохранение модели, GIF, автономный экспорт и экранирование данных.

Проверки выполняются с небольшим DOM-адаптером и **не заменяют проверку в настоящем браузере**. В этой среде браузерное подключение было недоступно; визуальный вид, touch, IndexedDB, Safari audio/clipboard и вставка в Genially не проверены автоматически. Перед использованием на уроке откройте редактор в своём браузере, загрузите пример и пройдите игру, затем скачайте HTML и повторите проверку без сети.

Проекты версии `schemaVersion: 1` принимаются; неизвестные версии отклоняются. HTML/JavaScript и SVG не принимаются как пользовательские медиа. Текст вопросов вставляется как текст; экспорт экранирует данные проекта и границы script. Встроенные SVG-иллюстрации входят в код приложения.
