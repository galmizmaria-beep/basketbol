# Ассеты «Баскетбол знаний»

Сгенерированы встроенным ImageGen (без CLI). Итоговые файлы проекта:

- `arena.jpg` — фон арены, 1280×720, JPEG.
- `hero.png` — герой, 400×600, прозрачный PNG.
- `hoop.png` — кольцо, 400×600, прозрачный PNG.
- `ball.png` — мяч, 160×160, прозрачный PNG.

Исходные PNG сохранены локально как `*-source.png`; в GitHub загружаются оптимизированные версии. Прозрачность героя, кольца и мяча проверена: угловые пиксели имеют alpha=0.
